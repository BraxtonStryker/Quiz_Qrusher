Using Quiz Qrusher Lite

Lite is a single file that works offline. It keeps one quiz at a time; the full version keeps a library of every quiz.

Taking a quiz

  1. Drop a question CSV on Home (headers: Category, Question_Text, Option_1 to Option_6, Correct_Option_Number) and press Start quiz.
  2. Answer, flag questions to revisit, and keep notes in the Notes tab on the right. The S button at the right of an option strikes it out; click your chosen option again to unselect it.
  3. Submit to see your score, weak categories and missed questions, then download a follow-up request for your AI model.

Saving

Progress saves automatically in this browser. To keep a copy, or to move a quiz to another device, use Download save file, then open that file on Home.

In Chrome or Edge on a computer you can also link a folder (Settings, Saving). Every change is then written there as a file too. Browsers ask for permission again after a restart: press Reconnect when it appears.

Other browsers can't link a folder, and some clear site data after about a week without visits, so download save files. Settings can remind you when you submit or every few minutes.

Settings

Changes show right away as a preview. Press Apply to keep them. Opened from a file, Lite stores its settings inside the file itself:

  • If you linked the folder that holds this Lite file, Apply updates the file in place and reloads.
  • Otherwise Apply downloads a new copy. Delete the old file, put the new one in its place, and open it again.

Suggested setup

A folder named Quiz Qrusher Lite holding quiz_qrusher_v3.0_lite.html. Link that folder in Settings (Chrome/Edge) and saves go into a saves folder inside it. In iCloud Drive or OneDrive, set the folder to “Always keep on this device”.
