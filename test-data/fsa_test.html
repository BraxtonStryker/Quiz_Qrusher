Folder-access test

Checks what the File System Access API can do when Quiz Qrusher is opened straight from disk. The results decide how Lite saves progress and applies settings. Nothing is sent anywhere.

  1. Open this file from disk in Chrome. The address bar should start with file:///.
  2. Step 1: choose the folder that contains this file ().
  3. Step 2: press F5. Step 3: press its button (the page rewrites itself and reloads). Step 4 runs on its own.
  4. Step 5: download the copy and open it from your Downloads folder.
  5. Step 6: quit the browser completely (menu, then Exit; also check the system tray), reopen this file, then press Record. If it asks, press Reconnect and answer the question. Pick "Allow on every visit" if it is offered.
  6. Step 7: quit and reopen once more, then press Record.
  7. Press Copy results and paste them to Claude. Then repeat everything in Edge.
This browser has no showDirectoryPicker, so it can't link a folder. Record that and try Chrome or Edge.

Not run

Rewrites the settings block inside on disk (adds 1 to a counter), then reloads. It passes if the reloaded page runs with the new counter. This is how Lite's Apply would update its baked settings in place.

Startup snapshot vs. file on disk

Is a snapshot taken at startup a faithful copy of the source?

Not run

Lite will rebuild itself from a snapshot of the page taken at startup. This compares that snapshot with the real file, read through the linked folder. It runs on its own once the folder is linked and allowed.
